Política de Privacidade

Última atualização: 13 de agosto de 2026

Esta política descreve o tratamento de dados pelo Atalho Digital Automação, um cliente privado operado pelo proprietário do canal Atalho Digital.

1. Identificação e contato

O Atalho Digital Automação é operado por um desenvolvedor independente e é destinado ao uso do próprio proprietário do canal Atalho Digital. Para dúvidas, solicitações de privacidade, exclusão de dados ou reclamações, entre em contato pelo e-mail andersonbnhgu@gmail.com.

2. Uso dos Serviços de API do YouTube

O Atalho Digital Automação usa os Serviços de API do YouTube, incluindo a YouTube Data API, para executar ações autorizadas pelo operador do canal.

Ao usar recursos relacionados ao YouTube, também se aplicam a Política de Privacidade do Google e os documentos aplicáveis dos Serviços de API do YouTube.

3. Dados acessados pela API

Dependendo da operação autorizada, o cliente pode acessar ou armazenar dados como:

  • identificador, nome e identificador público do canal autorizado;
  • identificador dos vídeos enviados;
  • título, descrição, tags/hashtags e configuração de visibilidade;
  • estado de processamento, envio e publicação do vídeo;
  • resultados técnicos retornados pela API necessários para registrar a operação realizada.

O cliente atualmente não acessa comentários, mensagens privadas, listas de contatos, dados de espectadores nem dados de outros canais para fins de perfilamento.

4. Dados locais do fluxo de produção

Separadamente dos dados fornecidos pela API do YouTube, o sistema pode armazenar localmente vídeos de entrada, transcrições, cortes, arquivos renderizados, legendas, metadados gerados, decisões de aprovação humana e registros técnicos do fluxo.

Esses dados são usados para preparar e publicar conteúdo próprio ou devidamente autorizado do canal. Eles não são apresentados como dados fornecidos pelo YouTube.

5. Finalidades

Os dados são usados apenas para as finalidades necessárias ao funcionamento do cliente privado, incluindo:

  • confirmar a identidade do canal autorizado;
  • enviar vídeos após aprovação explícita do operador;
  • aplicar título, descrição, tags e visibilidade escolhidos pelo operador;
  • registrar o identificador e o estado do upload;
  • diagnosticar falhas técnicas do fluxo.

6. Compartilhamento e venda de dados

Dados obtidos por meio da API do YouTube não são vendidos, alugados ou comercializados. O cliente não possui usuários externos e não fornece acesso a dados autorizados a terceiros.

O envio de dados ao Google/YouTube ocorre quando necessário para executar as operações solicitadas na própria API. Os dados obtidos da API do YouTube não são enviados a provedores de IA para criação de métricas derivadas.

7. Armazenamento e segurança

O ambiente operacional é privado. Os registros do fluxo são mantidos em infraestrutura controlada pelo operador, com acesso restrito. As credenciais OAuth são mantidas no mecanismo de credenciais do n8n e não são publicadas nas páginas deste site.

Dados da API sujeitos a atualização periódica são atualizados ou excluídos conforme os prazos aplicáveis das Políticas para Desenvolvedores do YouTube. Dados autorizados que não precisem ser mantidos de forma contínua não devem permanecer desatualizados por mais de 30 dias.

8. Exclusão de dados

O operador pode solicitar a exclusão dos dados armazenados pelo cliente pelo e-mail andersonbnhgu@gmail.com. Solicitações de exclusão de dados armazenados pelo cliente serão atendidas o mais rápido possível e, no máximo, em 7 dias corridos quando aplicável às políticas da API.

A exclusão de dados armazenados pelo Atalho Digital Automação não exclui dados ou vídeos armazenados pelo próprio YouTube. Para excluir conteúdo no YouTube, o operador deve usar um aplicativo do YouTube ou outro cliente autorizado que ofereça essa funcionalidade.

9. Revogação do acesso Google/YouTube

O operador pode revogar o acesso do cliente à Conta Google a qualquer momento pela página de permissões da Conta Google: configurações de segurança e permissões do Google .

Quando a autorização é revogada ou deixa de ser válida, o cliente deixa de usar a credencial para novas operações. Os dados da API associados à autorização revogada serão excluídos ou atualizados de acordo com os prazos aplicáveis das Políticas para Desenvolvedores do YouTube.

10. Consentimento e ações em nome do usuário

O operador autentica a Conta Google por OAuth e aprova expressamente as ações realizadas pelo cliente. Antes de cada upload, o fluxo apresenta para revisão o conteúdo e seus metadados e exige decisão humana. A visibilidade do vídeo é selecionada explicitamente entre Público, Não listado e Privado.

11. Mudanças nesta política

Esta política poderá ser atualizada se o cliente passar a acessar novos tipos de dados ou usar os Serviços de API do YouTube para finalidades diferentes. Alterações materiais serão refletidas nesta página antes de o novo uso entrar em operação.
