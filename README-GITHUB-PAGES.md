# Atalho Digital Automação — GitHub Pages

Este pacote contém as páginas públicas para o cliente privado da YouTube Data API:

- `index.html` — página principal / visão geral do cliente
- `privacidade.html` — Política de Privacidade
- `termos.html` — Termos de Uso
- `assets/styles.css` — estilos

## Publicação no GitHub Pages

1. Crie um repositório público no GitHub, por exemplo:
   `atalho-digital-automacao`

2. Envie **todo o conteúdo desta pasta** para a raiz do repositório.

3. No GitHub, abra:
   `Settings` → `Pages`

4. Em **Build and deployment**:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/ (root)`
   - Salve.

5. Aguarde o GitHub publicar o site por HTTPS.

A URL ficará parecida com:

`https://SEU-USUARIO.github.io/atalho-digital-automacao/`

## URLs para a Seção 4 do formulário

Depois de publicado, use:

Principal URL de acesso:
`https://SEU-USUARIO.github.io/atalho-digital-automacao/`

URL da Política de Privacidade:
`https://SEU-USUARIO.github.io/atalho-digital-automacao/privacidade.html`

URL dos Termos de Serviço:
`https://SEU-USUARIO.github.io/atalho-digital-automacao/termos.html`

Seu cliente da API pode ser acessado pelo público em geral?
`Não`

## Antes de enviar a auditoria

Abra as três URLs em uma janela anônima e confirme que carregam sem login.

Também vale manter evidências (capturas de tela) da Política de Privacidade, pois o formulário de auditoria pode solicitá-las.

## Observação importante

Estas páginas descrevem o funcionamento atual do cliente privado. Se o sistema passar a:
- atender usuários externos;
- acessar novos dados da API;
- usar métricas do YouTube em modelos/IA;
- compartilhar dados da API com terceiros;
- ou mudar a finalidade do uso,

revise a Política de Privacidade e os Termos antes de colocar a mudança em produção.
